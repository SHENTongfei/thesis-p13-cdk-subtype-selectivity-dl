# 基于深度学习的 CDK 细胞周期激酶亚型精准分类与活性定位

> 针对 CDK 家族亚型众多、功能重叠的特点，用深度学习实现亚型层面的活性精准定位，为细胞周期调控药物研发提供支撑。

## 一、方法

- **模型**：图卷积网络 GCN + Set2Set（LSTM）序贯读出

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：1690 条样本，2 类
- **标签协议**：abs_gap
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
